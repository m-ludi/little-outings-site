# little-outings.com

Website for the Little Outings app, served by GitHub Pages from this repository's main branch.

- `index.html`, `privacy/` and `support/` are the public pages. The privacy and support pages are linked from the App Store and Google Play listings.
- `app/` is the web version of the app, at little-outings.com/app/. It is built from the private app repo, so don't edit it here.
- `cities.json` lists the cities the app covers, with their neighborhoods and a link to each city's feed.
- `events/<city>.json` is each city's event list. The app downloads these, and they are refreshed weekly.
- `photos/` holds venue photos from Wikimedia Commons, each credited in the event that uses it.
- `CNAME` points GitHub Pages at little-outings.com.

## City feed format

```json
{ "version": 1, "city": "nyc", "updatedAt": "2026-11-04T09:00:00-05:00", "events": [ { "id": "...", "title": "...", ... } ] }
```

Each event needs a unique `id` and a `title`. Times are ISO 8601 with the city's own UTC offset.
`registration.opensAt` drives the app's alerts.
Set `registration.timeKnown` to `false` when the organizer gives a date but no time.
Don't edit these files by hand. They are generated by `scripts/import-city.py` in the app repo.
